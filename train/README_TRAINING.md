# Инструкция по Обучению Собственной Модели ArcFace (100% Proprietary IP)

Данный пайплайн позволяет вашей компании обучить **собственную коммерчески чистую ИИ-модель** распознавания лиц для применения в Аэропортах, Терминалах и Корпоративных системах.

---

## 📁 1. Структура Данных для Обучения

Создайте папку `data/faces/`. Каждая подпапка — это один человек (ID), в которой лежат его фотографии:

```
x:/Air biometric/
└── data/
    └── faces/
        ├── person_001/
        │   ├── photo1.jpg
        │   ├── photo2.jpg
        │   └── passport_crop.jpg
        ├── person_002/
        │   ├── scan1.png
        │   └── selfie.jpg
        └── person_003/
            └── ...
```

> **Где взять открытые коммерческие датасеты:**
> - **WebFace42M / CASIA-WebFace** (публичные наборы лиц под открытые исследования/коммерцию)
> - Внутренний датасет сотрудников/пассажиров вашей организации.

---

## 🚀 2. Запуск Обучения

Запустите скрипт обучения на локальном ПК или GPU-сервере:

```bash
python train/train.py
```

- Скрипт рассчитывает **ArcFace Loss (Additive Angular Margin)**.
- Выдает **512-мерный векторы лиц**.
- Автоматически сохраняет чекпоинт в `models/custom_arcface.pth`.

---

## 📦 3. Экспорт в ONNX для бэкенда

После завершения обучения сконвертируйте модель в формат `.onnx`:

```bash
python train/export_onnx.py
```

Файл **`models/custom_arcface_model.onnx`** будет создан.
